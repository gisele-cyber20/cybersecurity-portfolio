# AI Security Log Analysis

## Project Overview

This project demonstrates how artificial intelligence can assist cybersecurity analysts in reviewing and interpreting security logs. The goal was to evaluate how AI can support Security Operations Center (SOC) workflows by identifying suspicious activity, explaining security events, and recommending investigation steps.

Rather than replacing human analysts, AI is used as a tool to accelerate log analysis and improve the efficiency of threat detection and incident response.

---

## Objectives

- Analyze security log entries.
- Identify potential indicators of compromise (IOCs).
- Classify security events by severity.
- Determine possible attack techniques.
- Generate recommended investigation actions.
- Evaluate the benefits and limitations of AI-assisted analysis.

---

## Tools Used

- ChatGPT
- Windows Event Logs
- Linux Authentication Logs
- Security Documentation
- MITRE ATT&CK Framework

---

## Scenario

Security analysts regularly review thousands of log entries generated by operating systems, applications, and security tools. Manually reviewing every event can be time-consuming.

In this project, sample security logs were submitted to an AI model for analysis. The AI was tasked with identifying suspicious activity, explaining event significance, and suggesting next steps for investigation.

---

## Example Log Analysis

### Sample Event

```text
Event ID: 4625
Account Name: Administrator
Source IP: 192.168.1.50
Failure Reason: Unknown username or bad password
```

### AI Analysis

**Event Type:** Failed Login Attempt

**Risk Level:** Medium

**Potential Threats:**
- Password guessing
- Brute-force attack
- Unauthorized access attempt

**Recommended Actions:**
- Review authentication logs for repeated failures.
- Check source IP reputation.
- Verify whether the activity is expected.
- Monitor for successful logins following failed attempts.

---

## Linux Authentication Example

### Sample Log

```text
Failed password for root from 192.168.1.100 port 22 ssh2
```

### AI Analysis

**Event Type:** Failed SSH Authentication

**Potential Threat:**
- SSH brute-force attempt

**Recommended Actions:**
- Review additional SSH logs.
- Check for repeated login attempts.
- Implement account lockout policies.
- Restrict SSH access when appropriate.

## Findings

The AI was able to:

- Identify common security events.
- Explain log entries in plain language.
- Suggest investigation steps.
- Accelerate the triage process.

However, the AI also demonstrated limitations:

- It cannot validate real-world context.
- It may incorrectly assess severity.
- Human verification remains essential.
- AI recommendations should never replace analyst judgment.

---

## Lessons Learned

This project reinforced several important cybersecurity concepts:

- Log analysis is a critical SOC skill.
- AI can improve analyst efficiency.
- Human validation remains necessary.
- Security investigations require context and evidence.
- AI should be treated as an assistant rather than a decision-maker.
